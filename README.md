# testRTC
Этот проект тестирует часы реального времен в устройствах Umka7-02

## Описание проекта
Автоматический цикл включения питания, сбора данных и отключения устройства.
Этот проект предназначен для автоматического тестирования устройства, которое получает питание через реле, подключённое к Raspberry Pi. Скрипт циклически включает питание, ждёт загрузки устройства, получает от него данные по SSH, затем отключает питание и делает паузу перед следующим циклом.
## Проект полезен для долговременных тестов стабильности, проверки MAC‑адресов, времени, поведения при холодной перезагрузке и т. д.
Как работает цикл?
Каждый цикл выполняет следующие шаги:
- Включение реле (подача питания на устройство).
- Ожидание 2 минуты, чтобы устройство полностью загрузилось.
- Получение данных по SSH:
текущая дата/время устройства,
MAC‑адрес первого сетевого интерфейса.
- Запись результата в файл results.log

Формат строки:
```
номер_цикла; дата; mac
```

- Отключение реле (снятие питания).
- Ожидание 28 минут перед следующим циклом.
Цикл повторяется бесконечно.

## Требования
- Raspberry Pi (проверено на Raspberry Pi 4)
- Python 3
- Модуль RPi.GPIO (требуется доступ в Интернет)
- Доступ по SSH к тестируемому устройству
- Реле, подключённое к BCM 18 (физический пин 12), активное по LOW
- Виртуальное окружение

## Создать окружение и активировать его:
```
python3 -m venv venv 
source venv/bin/activate 
```

## Установить зависимости:
```
pip install RPi.GPIO 
```

### Запуск в tmux (рекомендуется для долгих тестов)
Создать новую tmux‑сессию:
```
tmux new -s power_test
```

## Активировать виртуальное окружение внутри tmux:
Kod
source venv/bin/activate 

## Запустить скрипт:
python3 all.py 

## Отсоединиться от сессии, оставив скрипт работать:
Ctrl + B, затем D 

## Вернуться в сессию позже:
tmux attach -t power_test 

## Логирование
Все результаты сохраняются в файл results.log. Каждая строка — один тест:
```
1; Wed Feb 18 11:04:46 UTC 2026; 7a:86:d3:a4:0f:b6 2; Wed Feb 18 11:34:52 UTC 2026; 7a:86:d3:a4:0f:b6 ... 
```

## Настройки
В скрипте можно изменить:
- IP‑адрес устройства
- SSH‑логин
- длительность включения
- длительность выключения
- путь к лог‑файлу
- GPIO‑пин реле
