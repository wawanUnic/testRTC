# testRTC
Этот проект тестирует часы реального времен в устройствах Umka7-02

## Описание проекта
Автоматический цикл включения питания, сбора данных и отключения устройства.
Этот проект предназначен для автоматического тестирования устройства, которое получает питание через реле, подключённое к Raspberry Pi. Скрипт циклически включает питание, ждёт загрузки устройства, получает от него данные по SSH, затем отключает питание и делает паузу перед следующим циклом.
## Проект полезен для долговременных тестов стабильности, проверки MAC‑адресов, времени, поведения при холодной перезагрузке и т. д.
Как работает цикл?
Каждый цикл выполняет следующие шаги:
- Включение реле (подача питания на устройство).
- Ожидание 2 минуты, чтобы устройство полностью загрузилось.
- Получение данных по SSH:
текущая дата/время устройства,
MAC‑адрес первого сетевого интерфейса.
- Запись результата в файл results.log
